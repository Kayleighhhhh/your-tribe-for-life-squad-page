# Agreements on cooperation 

## Communication
- Use MS Teams for communicating updates and decisions outside of the studio.
- Attend daily stand-ups, either online or in the studio (excluding weekends).
- Update the project board daily.
- Close issues immediately upon completion.
- Ask questions whenever needed.

## Code conventions
### Naming conventions
- Use kebab-case for classes, CSS variables and IDs in HTML and CSS.
- Use camelCase in JavaScript for JS variables and functions.
- Use English for naming things in code.

### HTML conventions
- Use semantic HTML.
- Use 1 tab - for indentation.

### CSS conventions
- Follow the HTML order in CSS.
- Use CSS nesting for more compact coding.
- Use `@media`-queries for styling use-preferences and responsive layouts.

### JS conventions
- Use comments to explain complicated code.
- Don't use semicolons `;` at the end of the code.
- Always use _const_ unless you need to reassign the variable, then use _let_.

### General conventions
- Reference issues in commits.
- When working on an issue, make a branch for your code.
- Use Pull Requests before pushing your branch to main, so we can review it.
